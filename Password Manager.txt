
DEVOPS PRACTICALS – COMPLETE STEP BY STEP GUIDE

==================================================
PRACTICAL 1: GIT INSTALLATION
==================================================

Aim:
Install Git on Windows system.

Steps:

Step 1: Download Git
1. Open browser.
2. Visit https://git-scm.com
3. Click "Download for Windows".
4. Download will start automatically.

Step 2: Run Installer
1. Open downloaded .exe file.
2. Click "Yes" if UAC prompt appears.
3. Click "Next".

Step 3: Installation Setup
1. Select required components.
2. Choose default editor.
3. Select initial branch name.
4. Configure PATH environment.
5. Choose HTTPS transport backend.
6. Configure line ending conversions.
7. Select terminal emulator.

Step 4: Finish Installation
1. Wait for installation.
2. Click "Finish".

Step 5: Verify Installation
1. Open Command Prompt or Git Bash.
2. Run command:
   git --version

Step 6: Configure Git
1. Configure username:
   git config --global user.name "Your Name"

2. Configure email:
   git config --global user.email "your@email.com"

PRACTICAL 2: CREATE A REPOSITORY (GITHUB)
==================================================

Aim:
Create and use GitHub repository.

Step 1: Login to GitHub
1. Open https://github.com
2. Sign in using your account.

Step 2: Create Repository
1. Click "+" icon.
2. Select "New repository".
3. Enter repository name.
4. Add description if needed.
5. Select Public or Private.
6. Click "Create Repository".

Step 3: Clone Repository
1. Open repository page.
2. Click "Code".
3. Copy repository URL.

Commands:
cd path/to/folder

git clone https://github.com/username/repository.git

cd repository

git remote -v

Step 4: Add File
1. Create file:
   echo "Hello Git!" > hello.txt

2. Stage file:
   git add hello.txt

3. Commit changes:
   git commit -m "Add hello.txt file"

Step 5: Push to GitHub
Command:
git push -u origin main

PRACTICAL 4: JENKINS INSTALLATION & SETUP
==================================================

Aim:
Install and configure Jenkins.

Step 1: Access Jenkins
Open browser:
http://localhost:8080

Step 2: Unlock Jenkins
1. Open file:
   C:\Program Files\Jenkins\secrets\initialAdminPassword

2. Copy password.
3. Paste into Jenkins unlock screen.

Step 3: Install Plugins
1. Click "Install Suggested Plugins".

Step 4: Create Admin User
1. Enter username.
2. Enter password.
3. Enter email.
4. Click "Save and Continue".

Step 5: Configure URL
1. Verify Jenkins URL.
2. Click "Save and Finish".

Step 6: Start Using Jenkins
1. Click "Start using Jenkins".

PRACTICAL 7: CI/CD WORKFLOW MANAGEMENT
==================================================

Aim:
Understand CI/CD workflow.

Continuous Integration Process:
1. Developers write code.
2. Code pushed to version control.
3. Branches merged into main branch.
4. Source code compiled.
5. Errors detected.
6. Build package created.
7. Automated unit testing performed.
8. Automated UI testing performed.
9. Final package prepared.

Continuous Delivery Process:
1. Deploy to testing environment.
2. Perform system testing.
3. Approval process completed.
4. Release application to users.

PRACTICAL 9: DOCKER COMMANDS
==================================================

Aim:
Learn basic Docker commands.

1. Check Docker version
   docker --version

2. Pull image
   docker pull nginx

3. View images
   docker images

4. Run container
   docker run nginx

5. View running containers
   docker ps

6. Stop container
   docker stop container-id

7. Start container
   docker start container-id

8. Remove container
   docker rm container-id

9. Remove image
   docker rmi image-id

PRACTICAL 10: CREATE CONTAINER AND PUSH TO DOCKER HUB
==================================================

Aim:
Create Docker container and push to Docker Hub.

Step 1: Create HTML File
Create:
index.html

Step 2: Create Dockerfile
Create:
Dockerfile

Example:
FROM nginx
COPY index.html /usr/share/nginx/html

Step 3: Build Image
Command:
docker build -t image-name .

Step 4: Run Locally
Command:
docker run -p 8080:80 image-name

Step 5: Create Docker Hub Repository
1. Open Docker Hub.
2. Click "Create Repository".

Step 6: Login from Terminal
Command:
docker login

Step 7: Push Image
Commands:
docker tag image-name username/image-name

docker push username/image-name
